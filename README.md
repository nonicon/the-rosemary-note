One line about a small good thing that happened today, written for the
[Make the Judge Smile](https://make.fun/bounty/u-gentle-badger-68-make-the-judge-smile-9228676d)
bounty on [make.fun](https://make.fun).

`main.py` writes the line to `/output/entry.txt`: a neighbour's gift of
rosemary, left outside a screen door with a note saying it smelled like
pine and forgiveness.

## Run

```sh
python3 main.py
```
